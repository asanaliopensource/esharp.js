# Esharp.js (E#.js)

Легковесный инструмент для сборки десктопных приложений на базе системного движка WebView2 с использованием XML-синтаксиса. Альтернатива тяжелым решениям вроде Electron.

## Пример использования (app.esharp.js)

```javascript
import { esharp } from 'esharp'

<Esharp>
    <exeName name="app.exe"/>
    <compileHtml2exe src="/index.html" />
    <icon src="/icon.ico"/>
</Esharp>

```

## Установка и запуск

1. Клонируйте репозиторий.
2. Установите зависимости:

```bash
npm install

```

3. Запустите компиляцию конфигурационного файла:

```bash
esharp app.esharp.js

```

## Структура проекта

* `src/cli/` - Подсистема разбора аргументов командной строки.
* `src/syntax/` - Модуль валидации и проверки синтаксиса.
* `src/compile2exe/` - Ядро компиляции в нативный исполняемый файл через C# / .NET.
* `main.ts` - Главный файл.
